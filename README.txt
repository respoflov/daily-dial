My Daily-Dial 🜸 — Daily Dial (PWA)
================================

원형 하루 계획표 앱입니다. 원판을 드래그해 일과를 색칠하고,
루틴을 체크하고, 매일의 기록이 자동으로 쌓입니다.

--------------------------------
1. 파일 구성
--------------------------------
index.html    앱 본체 (모든 기능 포함, 단일 파일)
manifest.json PWA 설치 정보
sw.js         오프라인 캐시(서비스 워커)
icon-192.png  앱 아이콘 (192px)
icon-512.png  앱 아이콘 (512px)
README.txt    이 문서

--------------------------------
2. 처음 열면 (랜딩 화면)
--------------------------------
- 앱 이름이 잠깐(약 1.8초) 뜬 뒤, 자동으로 "오늘 요약" 화면으로
  바뀝니다 (오늘 원판 미리보기 · 연속 작성일 · 오늘 일정 수 · 오늘의 말).
- 화면 아무 곳이나 탭하면 실제 편집 화면으로 들어갑니다.

--------------------------------
3. 사용 방법
--------------------------------
- 상단: 앱 이름 / 오늘 날짜(요일·평일·주말 자동 표시) / 다크모드 버튼.
  다크모드 버튼은 눌렀을 때 바뀔 모드를 보여줍니다
  (지금 라이트면 "D"=다크로, 지금 다크면 "L"=라이트로).
- 오늘의 말: 한 줄 입력, 매일 자동 저장됩니다.
  보관함의 "오늘의 말 모아보기" 탭에서 날짜별로 모아볼 수 있습니다.
- 버튼 줄(왼쪽부터): [모아보기/나눠보기] [오전/오후] [보관함] [저장].
  - 모아보기: 24시간 한 바퀴 보기. 나눠보기 상태에선 오전/오후로 전환.
  - 저장: 누르면 "PNG 저장" / "인쇄로 저장" 메뉴가 뜹니다.
    (보관함 저장은 이제 버튼 없이 자동으로 이루어집니다. 아래 5번 참고)
- 일과 추가: 원판 위를 누른 채 드래그 → 손을 떼면 활동명/시간/색 입력창.
  별표(☆)는 활동명 입력칸 바로 옆에 있습니다.
  (모아보기에서는 자정을 가로지르는 드래그도 가능)
- 일과 수정/삭제: 원판의 색칠 부분을 탭하거나, 아래 일과 목록을 탭.
- 스냅: 10분 단위로 고정되어 있습니다.

--------------------------------
4. 주간 스트립 · 루틴 체크
--------------------------------
- 원판 아래 7칸: 이번 주(월~일) 중 일과를 기록한 날이 채워져 표시됩니다.
  오늘 칸은 테두리로 표시됩니다.
- 오른쪽 4칸(수면 · 운동 · 독서 · 식사): 누르면 그날 완료 여부가
  켜짐/꺼짐으로 바뀝니다. 매일 자정에 자동으로 초기화됩니다.

--------------------------------
5. 일과 목록
--------------------------------
- 같은 이름의 일과가 하루에 하나뿐이면: 목록을 누르면 바로 수정/삭제
  창이 열립니다.
- 같은 이름의 일과가 여러 개면: 목록을 누르면 원판에 그 일과만 남고
  나머지는 숨겨집니다 (다시 누르면 해제).

--------------------------------
6. 일과 메모 (errands / healing)
--------------------------------
- "일과 메모" 옆 화살표를 누르면 펼침/숨김 (버튼이 아니라 그 줄 전체를
  탭하면 됩니다).
- errands: 체크박스가 있는 할 일 목록. 완료 시 취소선 표시.
- healing: 자유 메모.
- 각 칸은 기본 2줄이며, "+ 줄 추가"로 늘릴 수 있습니다.
  기본 2줄은 삭제할 수 없고, 추가한 줄만 삭제 가능합니다.
- 글이 길어 잘려 보일 때는 그 줄을 꾹 누르면(롱프레스) 전체 문장이
  팝업으로 뜹니다. 추가된 줄이면 팝업 안에 삭제 버튼도 함께 뜹니다.
  화면을 한 번 더 탭하면 팝업이 닫힙니다.

--------------------------------
7. 보관함
--------------------------------
[보관함] 버튼을 누르면 아래 3개 탭으로 전환됩니다.

- 최근 12주 작성 현황: 12주간의 기록 히트맵 + 연속 작성일 · 최장 연속 ·
  오늘 일정 수 · 이번 주 작성 · 총 기록일 통계. 채워진 칸을 누르면
  그 날의 원판 미리보기 · 오늘의 말 · 루틴 체크 결과 · 일과 · errands ·
  healing이 요약되어 뜨고, 그 자리에서 불러오기 / 오늘 일정에 복제 /
  삭제를 할 수 있습니다.
- 루틴 기록: 수면 · 운동 · 독서 · 식사 4개 항목이 각자의 12주 히트맵으로
  따로 표시됩니다.
- 오늘의 말 모아보기: 그동안 적은 오늘의 말을 날짜순으로 모아볼 수 있습니다.

계획표는 이제 매일 자동으로 저장됩니다 — 날짜가 바뀌면 새 계획표가
자동으로 시작되고, 이전 날짜 계획표는 자동으로 보관함에 남습니다.
("오늘 일정에 복제"는 과거의 계획표 내용을 오늘 날짜에 덮어씁니다.
확인 창이 뜨니 실수로 오늘 내용을 잃을 걱정은 없습니다.)

--------------------------------
8. 다크모드
--------------------------------
처음 열면 기기의 시스템 설정(라이트/다크)을 따르고, 상단 버튼으로
언제든 수동 전환할 수 있습니다. 원판 위 일과 이름 글자는 다크모드에서도
항상 어두운 색을 유지합니다 (파스텔 색 배경 위에서 잘 보이도록).

데이터는 모두 이 기기 브라우저(localStorage)에만 저장됩니다.
브라우저 데이터를 지우면 계획표도 삭제되니 중요한 계획표는
PNG로도 내보내 두는 것을 권합니다.

--------------------------------
9. 실행 / 배포
--------------------------------
(1) 바로 열어보기
    index.html을 브라우저로 열면 모든 기능이 동작합니다.
    단, PWA 설치·오프라인 기능은 HTTPS 호스팅에서만 활성화됩니다.

(2) GitHub Pages로 배포 (무료, 권장)
    1. github.com에서 새 저장소 생성 (예: daily-dial)
    2. 이 폴더의 파일 5개(README 제외 가능)를 업로드
    3. 저장소 Settings → Pages → Branch: main / (root) → Save
    4. 잠시 후 https://<아이디>.github.io/daily-dial/ 에서 접속
    5. 휴대폰 브라우저에서 접속 → "홈 화면에 추가"로 앱 설치

(3) 그 외 Netlify Drop, Cloudflare Pages 등에 폴더를 끌어다 놓아도 됩니다.

--------------------------------
10. 참고
--------------------------------
- 수면처럼 자정에 걸친 일과는 나눠보기에서 두 원판에 나뉘어 보이지만,
  일과 목록의 누적 시간에는 전부 합산됩니다.
- 색은 저채도 8색 팔레트로 제한되어 있습니다(가독성 목적).
- sw.js의 CACHE 버전 숫자는 index.html/manifest.json 등을 바꿔 다시
  올릴 때마다 하나씩 올려주어야, 이미 방문했던 사용자도 새 버전을
  받아볼 수 있습니다.
